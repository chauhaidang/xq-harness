# Architecture and Decision Docs

Open deeper docs only when the task has design or behavior implications.

## Decision and design sources

- `docs/decisions/` — accepted architectural and naming decisions
- `docs/product/` — product-oriented context
- `docs/stories/` — story-level task background
- `README.md` — contributor overview
- `CATALOGUE.md` — consumer-facing package catalogue

## Use this topic when

- Changing public behavior
- Renaming or reorganizing published package surfaces
- Touching release or CI behavior
- Working from a product/story request

## Do not use this topic when

- The task is clearly scoped to one module implementation detail
- You only need commands or a module path
- You have not yet identified the target feature/module
